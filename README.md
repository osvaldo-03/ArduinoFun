# These are porjects that I have coded and built in arduino. 

Projects Overview
Dark Sensing LEDs
For this project, I added a photoresistor and a transistor to the LED strips in my room. This setup allowed the LED strips to automatically turn on when the room lights were off, creating a simple yet effective dark-sensing system.

Laser Targeting System
I used an ultrasonic sensor, a laser diode, and a servo motor to create a motion-based targeting system. When the ultrasonic sensor detects movement, the laser moves accordingly, simulating an automated targeting mechanism.

Xmas Motion Detector
This project uses an ultrasonic sensor, a buzzer, and LEDs to play Christmas songs and create a synchronized light show when it detects movement. Since I only used components from the Arduino starter kit, I had to rely on a buzzer instead of a speaker. The most challenging part was researching musical notes and their corresponding frequencies while also recalling note durations from my music class days. Additionally, I synced the LEDs to blink in time with the notes, enhancing the festive effect.
